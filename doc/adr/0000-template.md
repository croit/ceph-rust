# 0634 Title: the decision in a few words

Status: proposed | accepted | accepted, amended (am. N) | superseded-by-NNNN | rejected
Date: YYYY-MM-DD
Supersedes: NNNN (optional)
Amends: NNNN (optional)

## Context

The problem, requirement or constraint that makes a decision necessary.
Facts only. 1 to 5 sentences.

## Decision

The decision, stated in direct form: "croit-flashstore-osd does X." or "X is Y."
One rule per line. Use a list when there are several rules.

## Rationale

Why this option was chosen, using established facts only. Name the
trade-off that was accepted. If the rationale is unknown, write
"Rationale: not recorded" and add an entry under Open questions.

## Consequences

- Positive and negative effects, one per line. Prefix each with `+` or `-`.

## Alternatives

- Rejected option: reason in one line. Omit the section if none were recorded.

## Open questions

- Question that needs a human decision. Also list it in doc/90-open-questions.md.
  Omit the section if there are none.
