# 0233: one kernel selector for independent client identities
Status: superseded 2026-10-28 (ClientGroup/SharedClient removed: unused in production, no consumer)
Date: 2026-10-15
Context: [ADR: client efficient idle default](0402-client-efficient-idle-default.md) forbids mandatory busy core/thread/VF per client identity. Single Client owns a selector; multiple identities need shared scheduling without merging CephX/TID/request/credit/fence state.
Decision: static ClientGroup<D:TcpOwner> owns a fixed bounded set of fresh owners. All start on one reactor clock; budgeted round-robin progress/timers and fair per-command IO polling. Every source stream ID must be nonzero/non-reused (existing TcpOwner contract). Translate global=local*member_count+slot with checked arithmetic; quotient/remainder reverses routing without maps/allocations, fixed membership prevents aliasing. Overflow retires offending member, never wraps. Group-domain ClientId prevents cross-group stale handle use. Child failures/explicit close revoke all its streams immediately, emit one bounded retirement event and preserve owner/result access; other members continue. After retirement-event transfer, caller owns draining that inactive child's results; group stops scheduling it. Shared selector/clock/output/system failures remain reactor-wide. No cross-identity fence/order or retry implied.
Readiness: retained group events prevent wait; all active owners must prove can_sleep; aggregate earliest active timer. Child can_sleep contract must expose budget work or timers, so unvisited runnable owners cannot be hidden by group budget. Owner mutation/polling does not invent a permanent dirty bit; each owner remains authority on its ready work. Bounded timer/progress visits cannot remove another member's due deadline. Fixed membership retains slots/IDs until whole group dropped; no replacement/reuse API.
Native entry: SharedClient = KernelTcp<ClientGroup<NativeClient>>, GroupMemberConfig owns bootstrap and explicit protocol limits; defaults reuse ClientLimits protocol values. Global KernelTcpLimits supplied separately; capacity must cover sum of declared monitor/OSD maxima. Aggregate/per-member credits remain explicit separate bounds; shared staging/system error can stop whole reactor. No background workers, mailbox or automatic transport fallback. Generic KernelTcp/Client remain.
Qualification: own overlapping local IDs, callback/output/revocation/overflow isolation, fairness/budget/timer/clock and retirement/result/event lifecycle tests; actual kernel-only1/10/100 independent authenticated identities on one selector/thread, distinct per-member data, CRC/Secure idle/resume/resource evidence. Generic child failure and actual native close with surviving peers qualified; actual native rejection/failure remains open. Short VM qualification only, no full production/performance claim. Shared submission notification, global backpressure/indexed readiness, broader faults/ops/platform/mixed/full W/N remain required.
