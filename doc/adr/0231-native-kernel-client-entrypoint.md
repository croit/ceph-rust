# 0231: native kernel client without lab dependencies
Status: accepted
Date: 2026-10-15
Context: [ADR: client efficient idle default](0402-client-efficient-idle-default.md) selects kernel TCP default direction. ADR0228-0173 adapter was gated through lab, unnecessarily enabling fault fixtures/diagnostics for ordinary consumers. Native protocol/ownership already transport-neutral.
Decision: feature kernel = experimental + optional Mio; kernel-lab becomes compatibility alias kernel + lab. KernelTcp and normal Client entry compile under kernel alone. No Cargo default feature enabled while full W/N remains experimental. Client is a static KernelTcp<NativeClient> alias with from_config(BootstrapConfig, ClientLimits); starts bootstrap but opens no socket until step drives queued commands. Defaults compose existing session/request/TCP bounds plus32 managed-watch slots/4MiB reserved control and managed-target credit. Caller may disable/resize watches. Validate TCP limits and capacity for declared monitor+OSD slots before starting; retain typed session/request/transport errors without config secrets. No worker, background runtime, protocol alternative or automatic DPDK fallback. Protocol APIs available through explicit owner()/owner_mut(), sharing driver elapsed time; borrowed metadata/control traits remain on that owner.
Consequences: usable native kernel entry without lab gates, normal bounded managed-watch capacity and existing API ownership. Generic KernelTcp remains available for custom owners. Existing DPDK and opt-in kernel-lab profiles preserved. No claim of complete production qualification merely by removing lab dependency: shared reactors/mailboxes, complete efficient waits, kernel fault/platform/mixed/performance/full W/N gates remain. Kernel native API convenience forwarding may follow without changing engine policy.
Qualification: affected kernel-only/lab compatibility/DPDK builds and own constructor clock/capacity/close/admission/resource tests; cargo metadata verifies kernel lacks lab/DPDK features and DPDK-only excludes Mio. Build and run actual read/paused-read/watch CRC/Secure qualifiers with kernel alone via from_config and default limits. Existing test expectations retained; no lab fault injection substituted for production behavior.
